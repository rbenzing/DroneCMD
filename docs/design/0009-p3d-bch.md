## 1. Overview

### Goal

Implement primitive narrow-sense **binary BCH** codes with **hard-decision, errors-only** bounded-distance decoding, plugged into the P3a `Codec` framework, **maximally reusing `core/galois.py`** from P3c. Encode (generator polynomial from minimal polynomials) is the new work; decode is RS's syndrome→Berlekamp-Massey→Chien machinery **minus Forney** — because errors are binary, a located error position is simply a bit flip (magnitude always 1). BCH is hard-input and routes through the pipeline's existing **hard** coded-decode branch (the one `rep3` uses); it is the first multi-bit-correcting code to exercise that branch.

### What P3a/P3b/P3c already provide (build on, don't rebuild)

- `core.galois`: `GF2m(m, prim_poly)` (field + polynomial algebra, `poly_div` etc.); `GF256 = GF2m(8, 0x11D)`; `berlekamp_massey(field, synd, nsym, erase_count=0) -> locator` (Convention A, highest-degree-first); `chien_search(field, err_loc, nmess) -> positions`. All field-parametric — verified on GF(2^6) in P3c.
- `core.coding`: `CodeFamily.BCH`; `CodingSpec` with `soft_input` property (defaults False); the `Codec` protocol; `make_codec` (raises `NotImplementedError` for BCH today); `CODING_CATALOG["bch_63_51"]` registered as a descriptor (`gf_m=6, t=2`); `frame_with_crc`/`check_and_strip_crc`; `interleave`/`deinterleave`; `CODING_INTERLEAVE_DEPTH`.
- `core.profiles`: `SCProfileSpec(..., coding=None)`, `coding_of`, `SC_CATALOG`.
- `validation.pipeline.single_carrier_region_to_bytes`: the **hard** coded-decode branch (hard demod → `deinterleave(bits)` → `codec.decode(hard_bits)` → `check_and_strip_crc`), currently used by `rep3`. **BCH reuses this branch unchanged.**
- The `coded_link` (coded-BER/FER) metric.

### Non-goals

- No soft-decision BCH (Chase-2 etc.) — classical hard-decision bounded-distance only.
- No errors-and-erasures for BCH (hard input has no erasure source).
- No multi-block framing — the whole frame fits in one shortened GF(2^8) codeword; the GF(2^6) code is a unit-level demonstrator on small payloads.
- No OFDM BCH profile; no other codec families (P3e+).

## 2. `core/coding.py` — `_BCH` codec + generator helpers

New module helpers (BCH-specific; the field/BM/Chien come from `galois`):

- `_bch_min_poly(field: GF2m, i: int) -> List[int]` — the minimal polynomial of `α^i`: the product over the cyclotomic coset `{ (i * 2**s) mod field.n }` of `(x − α^j)`, computed with `field.poly_mul`. The result has **binary** coefficients (0/1); returned highest-degree-first.
- `_bch_generator_poly(field: GF2m, t: int) -> List[int]` — the product (LCM, since minimal polys are distinct and irreducible) of the *distinct* minimal polynomials `_bch_min_poly(field, i)` for `i = 1 … 2t`. Conjugate roots share a minimal polynomial, so collect distinct ones (deduplicate by value). `deg(g) = n − k`.

`class _BCH`:
- `__init__(spec)`: reads `gf_m`, `t`, `prim_poly` (default 0x11D); `self.field = GF256 if (gf_m==8 and prim==0x11D) else GF2m(gf_m, prim)`; `self.n = field.n`; `self.t = t`; `self.gen = _bch_generator_poly(field, t)`; `self.nsym = 2*t`; `self.parity_len = len(self.gen) - 1` (= `deg(g)`).
- `encode(info_bits: Bits) -> Bits`:
  - Treat info bits as the high-order coefficients of the message polynomial `m(x)` (highest-degree-first, matching `galois`).
  - `_, parity = field.poly_div(list(info_bits) + [0]*self.parity_len, self.gen)` (binary coeffs; `field.poly_div` divides correctly since {0,1} ⊂ GF(2^m)).
  - Return `concatenate(info_bits, parity)` as `uint8` bits (systematic codeword).
- `decode(received: SoftOrHard) -> DecodeResult`:
  - Hard bits: if float LLRs are passed (total-function fallback), map by sign (`L<0 ⇒ 1`); else take the uint8 bits directly.
  - `N = len(bits)`; `k = N - self.parity_len`. If `k <= 0`, return empty.
  - `synd = [field.poly_eval(list(bits), field.pow(2, j)) for j in range(1, self.nsym+1)]` (S_1 … S_{2t}; received bit-poly highest-degree-first).
  - If all `synd == 0`: no errors → return the first `k` bits (message).
  - Else, `try`: `err_loc = berlekamp_massey(field, synd, self.nsym)`; `err_pos = chien_search(field, err_loc[::-1], N)`; **flip** `bits[p]` for each `p in err_pos`; recompute syndromes; if any nonzero → uncorrectable. On success return corrected first `k` bits; on any raise (`ValueError`, `ZeroDivisionError`) or nonzero recheck → return the **received** first `k` bits unchanged (loud: CRC rejects).
  - `DecodeResult(bits, meta={"decode_ok": ..., "n_errors": len(err_pos)})`.

`make_codec` gains a `CodeFamily.BCH` branch → `_BCH(spec)`.

Convention note (identical to RS, final-review-verified): received/codeword bits are the polynomial coefficients highest-degree-first; a symbol/bit at array index `i` has locator `α^i`; `chien_search` maps a root `α^{-i}` back to position `N-1-i`. Encode and decode share this convention, so decode inverts encode for shortened `N < n`.

## 3. Catalog

- **Update** `bch_63_51`: params `{gf_m: 6, t: 2, prim_poly: 0x43}` (n=63, deg g=12, k=51; `soft_input` absent ⇒ False). GF(2^6) unit-level demonstrator.
- **Add** `bch_255_239`: `{gf_m: 8, t: 2, prim_poly: 0x11D}` (n=255, deg g=16, k=239). Standard primitive BCH, t=2.
- **Add** `bch_255_223`: `{gf_m: 8, t: 4, prim_poly: 0x11D}` (n=255, deg g=32, k=223). Standard primitive BCH, t=4. (Shares n,k with RS(255,223) but is a binary code — distinct.)
- All three are hard-input (no `soft_input` key). No existing codec had a working BCH implementation, so updating `bch_63_51` is behavior-additive.

## 4. Profile & pipeline integration

### 4a. `core/profiles.py`
- One new PHY-distinct coded profile: `bch_bpsk = SCProfileSpec("bch_bpsk", SCMod.BPSK, SCProfile(sps=128), coding="bch_255_223")` (t=4 for a clear coding-gain demonstration). **sps=128 is unique** in `SC_CATALOG` (existing: 4/8/16/32/64). Existing profiles unchanged.

### 4b. `validation/pipeline.py` — no change
BCH is `soft_input=False`, so `single_carrier_region_to_bytes` already routes it through the **hard** coded-decode branch (`hard demod → deinterleave(bits, CODING_INTERLEAVE_DEPTH) → make_codec(spec).decode(bits).bits → check_and_strip_crc`), identical to `rep3`. `deinterleave` on hard bits is an exact inverse, so BCH decodes the correct bit order. Loud-on-failure unchanged.

### 4c. synth / metric — no change
`modulate(coding=…)` already calls `codec.encode` generically (`_BCH.encode` slots in). The `coded_link` metric is unchanged.

## 5. Testing strategy

TDD; executed subagent-driven with per-task review. Buckets:

1. **Min-poly + generator:** `_bch_min_poly(GF256, 1)` has degree 8 and binary coefficients; `_bch_generator_poly` degree = 16 (GF(2^8) t=2), 32 (GF(2^8) t=4), 12 (GF(2^6) t=2); `g(α^i) = 0` for `i = 1 … 2t`.
2. **Encode systematic:** parity length = `deg(g)`; a clean codeword's syndromes are all zero (`c(α^j) = 0`, j=1..2t).
3. **Noiseless round-trip, all three codes (shortened):** `encode → decode` recovers the payload with `crc_ok` for `bch_255_239`, `bch_255_223`, `bch_63_51`.
4. **Error correction:** inject up to `t` bit errors → exact recovery; `t+1` bit errors → uncorrectable, CRC fails loudly (no silent wrong payload).
5. **Coding gain:** on the SNR sweep at matched PHY, BCH BER < uncoded BER at low SNR, measured through the full synth → **hard** demod → BCH → CRC chain.
6. **Blind end-to-end:** a `bch_bpsk` dataset routes through the pipeline's **hard** coded-decode path, blind-resolves `bch_bpsk`, decodes correctly, and populates `coded_link`.
7. **GF(2^6) unit:** `bch_63_51` encode/decode/error-correction on ≤51-bit payloads — proves the parametric field works for BCH across two field sizes.
8. **Loud-failure + regression:** CRC loud-failure at very low SNR; full existing suite (P1/PE/PH/P2/P3a/P3b/P3c) green; `mypy validation` clean.

## 6. Global constraints (bind every task)

- `mypy validation` is the CI gate — clean (no `Any`; `numpy.typing`). New/modified `core/*` files `mypy`-clean, minimal diffs, no whole-file `black` reformat, no new legacy findings. Lint every touched `tests/validation` file.
- IQ boundary `complex64` / internal `complex128`; LLRs `float64`; bits `uint8`; GF symbols plain `int` in `galois`.
- Deterministic encode (no RNG).
- **Loud on failure:** CRC failure, no lock, or uncorrectable BCH ⇒ `b""` / unchanged received bits that CRC rejects — no silent wrong payload at normal SNR. Existing hard/uncoded/conv/RS paths byte-for-byte unchanged.
- Additive: `bch_63_51` gains a working codec + params but no existing test changes behavior; existing profiles/tests unchanged; the pipeline hard branch is reused, not modified.
- Executed subagent-driven with TDD and per-task review; on `feature/ofdm-full-chain`; **no PR/tag** this sub-phase.
- **Subagent-stall guard:** the full validation suite (~6.5 min) and the blind-resolve set (~13 min) stall implementer subagents on backgrounded runs. Task briefs instruct running only targeted test files; the full-suite closing gate runs in the foreground / by the controller. Never background a slow test run in a subagent.
- GF-polynomial coefficient convention: highest-degree-first (index 0 = highest power), matching `galois` and RS.
